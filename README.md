The courses and tools below are the ones I use. 

## Education

- **[llm-education](https://github.com/michalkonik/llm-education)**: how local models work, how to build an agent you can trust, and how to secure it. English and Polish.
- **[financial-education](https://github.com/michalkonik/financial-education)**: practical macroeconomics for investors, from public data. English and Polish. Not financial advice.

## Local models and agent tools

- **[local-llm-quality-bench](https://github.com/michalkonik/local-llm-quality-bench)**: grades an open model as an agent, in Polish and English. Any OpenAI-compatible server, including vLLM and llama.cpp.
- **[local-llm-perf-bench](https://github.com/michalkonik/local-llm-perf-bench)**: how fast a GGUF model runs, with the conditions recorded next to the numbers.
- **[local-llm-bench-results](https://github.com/michalkonik/local-llm-bench-results)**: quality and speed measured on a 4× Radeon rig.
- **[local-rig-tools](https://github.com/michalkonik/local-rig-tools)**: an MCP server and a desktop GPU monitor, so a local model can do things without cloud keys.
- **[local-rig-skills](https://github.com/michalkonik/local-rig-skills)**: agent skills for cited web research, YouTube transcripts, and a summary you can read instead of the talk.
- **[autonomous-deal-hunter](https://github.com/michalkonik/autonomous-deal-hunter)**: watches used-hardware listings and estimates resale profit. It never buys.

## Financial tools

- **[family-finance-planner](https://github.com/michalkonik/family-finance-planner)**: compare big money decisions over decades. English, Polish, Russian, and Spanish.
- **[portfolio-rebalancing-simulator](https://github.com/michalkonik/portfolio-rebalancing-simulator)**: replay a crypto rebalance on stored Binance 4-hour candles. The page is the app.
